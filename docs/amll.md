# AMLL 歌词与背景

使用固定版本 `@applemusic-like-lyrics/core` / `@applemusic-like-lyrics/react` 0.6.0，按需加载歌词渲染器与 MeshGradient 流体背景。界面上的「AMLL · 源码」提供项目源码入口，第三方许可证保存在 `apps/web/public/licenses/AMLL-AGPL-3.0.txt`。

## 能力边界

| 模块             | 提供的能力                                               | 本项目采用方式                                 |
| ---------------- | -------------------------------------------------------- | ---------------------------------------------- |
| core / react     | 歌词逐词遮罩、发光、弹簧滚动、间奏、翻译与音译、流体背景 | 通过 `AmllLyrics` / `AmllBackground` 接入      |
| react-full       | 播放器界面、进度控件及播放、定位、音量等回调             | 不引入；保留 coss ui 播放控件                  |
| 完整 AMLL Player | 独立播放器应用                                           | 不是可直接替换浏览器 AudioTransport 的音频引擎 |
| FFT              | 音频频谱分析                                             | 未引入；背景不声称随节拍律动                   |

AMLL 核心组件不播放或解码音频。`react-full` 的 `onPlayOrResumeAtom`、`onSeekPositionAtom`、`onChangeVolumeAtom` 等将控制操作交给宿主实现，不能代替网易云鉴权、音频来源、试听范围或保音高变速。媒体仍由 `useAudioPlayback`、`AudioTransport`、Signalsmith Stretch 管理，不重复创建音频元素或 AudioContext。

参考：[组件快速入门](https://amll.dev/en/guides/component/quickstart.html)、[react-full 回调源码](https://github.com/amll-dev/applemusic-like-lyrics/blob/main/packages/react-full/src/states/callbacks.ts)、[react-full README](https://github.com/amll-dev/applemusic-like-lyrics/blob/main/packages/react-full/README.md)。

## 歌词转换与同步

`#lib/amll-lyrics` 将 `TimedLine[]` 转换为 AMLL 的 `LyricLine[]`，时间从原曲秒转换为整数毫秒。网易云官方逐字数据保留字词区间、间隙与行结束时间；只有 LRC 时一行作为一个 word，界面标注「句级近似进度」。近似显示按句起止时间推进，不代表真实字词演唱时间，不向歌词数据添加推算的逐字时间。空白行不渲染，但仍作为上一句结束边界。转换同时保留源索引，点击渲染后的行仍使用原 `seekLine` 校验实际可播放范围。

AMLL 0.6 默认将全部单 word 的歌词判为非动态，只渲染整句。`#lib/amll-player` 通过 React 的 `lyricPlayer` 扩展入口提供 `MediaClockLyricPlayer`，覆盖受保护的 `isNonDynamic` getter，让单句也能使用 AMLL 的渐进遮罩。选择其 CSS 遮罩路径（`supportMaskImage = false`），遮罩读取 core 更新的 `--amll-player-time`，避免 Web Animations 以墙钟 1× 运行而在慢速播放时提前完成。保留 AMLL 的布局与滚动，不重写字词 DOM；升级依赖时复验这两个扩展点、CSS 遮罩、暂停、倍速和字词间隙。

翻译和罗马音分别通过 `translatedLyric`、`romanLyric` 提供。数组只按歌词数据及时长缓存，显示开关不改变数组，避免播放器每次进度或显示选项变化重新构建并冻结歌词。AMLL 0.6 没有独立辅助行显示开关；显示状态通过播放器外层的数据属性控制辅助行透明度，保留其自然高度及同一 DOM，播放器容器的 class 保持稳定。开关使用 150ms、无延迟的透明度过渡，减少动态效果时立即切换。coss Switch 使用 Base UI 的原生 button 渲染，避免嵌套原生 label 时一次点击再次激活隐藏 checkbox，造成状态反转与闪烁；歌词开关滑块保持白色，仅移动位置及改变轨道颜色。

辅助行以文字渐变显示句内进度，读取与日文遮罩相同的 `--amll-player-time` 原曲时钟，暂停、倍速、定位和循环保持同步。`MediaClockLyricPlayer.rebuildLyricView` 为全部歌词对象（包含暂时脱离 DOM 的虚拟列表行）绑定原句起止时间，不能用当前可见 DOM 的顺序匹配歌词。辅助行没有独立逐字时间轴，因此始终为句级线性近似，不推算或伪装成翻译 / 罗马音的真实逐字时间；有日文逐字数据时界面同时标注「辅助行近似」。已固定的 0.6 DOM 顺序为主歌词、翻译、罗马音，升级时需要复验。歌词列表仍按开关省略辅助文本。禁用 AMLL 默认提前最多 600ms 的优化，以及行时间戳重写，保持学习界面与官方原曲时间轴一致。

逐帧读取 `AudioTransport.currentTime`，不能依赖 DSP 模式下隐藏音频元素的时钟。暂停、定位、循环和倍速都使用同一原曲时钟。歌词视口由 AMLL 单独滚动，手动滚动后由其滚动引擎暂缓自动跟随；点击歌词或「回到当前句」后重置跟随。「回到当前句」读取原曲时钟，并在 `resetScroll()` 后显式重新计算布局，保证暂停或仍在同一句时也立即归位，不跳转音频位置。手机关闭非当前歌词的模糊效果，保留清晰的阅读文字。

## 操作与降级

AMLL 0.6.0 动态歌词为指针点击的 DOM 展示。本项目通过 coss Dialog 的「歌词列表」提供完整文字阅读及 Tab / Enter 定位；弹窗关闭后恢复触发器焦点，播放快捷键不会抢占弹窗与控件。动效不可用时显示同一歌词列表，音频不被卸载。

歌词渲染器在工作区隐藏后停止逐帧更新。背景只在播放且区域可见时运行；暂停保留画面。系统减少动态效果时，背景使用静态模式，歌词关闭弹簧、缩放及模糊。封面静态图层作为加载与 WebGL 不可用时的背景。

顶部歌曲信息、练习提示与底部源码区域使用渐隐的背景模糊层，与同一封面背景连续衔接；歌词视口上下使用透明渐变，避免滚动文字在边界硬切。遮罩仅作用于背景与歌词边缘，不模糊提示文字或控件，也不拦截点击。

歌词面板用同一层圆角裁剪限制动态背景、canvas、歌词及顶部 / 底部模糊层，播放与暂停保留相同轮廓。面板通过 `transform-gpu` 建立合成层，防止 Chromium 在 WebGL 背景播放时绕过祖先圆角裁剪；仅设置 `overflow` 或 `clip-path` 不足以保证实际画面。全屏将圆角与裁剪半径一起展开为零，退出恢复，不重新挂载背景或歌词。

## 全屏播放

底部「全屏播放」同时适用于网易云与本地音频。`usePlayerFullscreen` 在点击时请求根元素的 Fullscreen API，让挂载到 body 的 coss Select / Dialog 继续可见；监听 `fullscreenchange` 同步浏览器退出，退出按钮及 Esc 恢复播放器按钮焦点。浏览器不支持或拒绝系统全屏时，提供明确提示并使用窗口内全屏，打开的弹窗和菜单优先处理 Esc。

全屏只改变布局和可见性，不重新挂载媒体、AMLL 或播放器 portal。侧栏、页头及网易云曲库收起，手机强制显示歌词面板并解除其 inert；退出后恢复原导航与手机页签。从其他页面点击播放器全屏时展示当前音频所属工作区，退出仍回到原页面。没有新增音频元素或播放器状态。

侧栏、页头与曲库通过 grid 轨道收缩及渐隐收起，主画布和歌词区域的宽高连续扩展，播放器边距与面板圆角同步变化。进入使用 400ms、退出使用 350ms 的 smooth-out 过渡；收起区域保持挂载并设为 inert，避免过渡期间接收焦点。系统减少动态效果时立即切换。

## 本地验证范围

真实网易云歌曲验证使用 LONGMAN 的《spiral》：原生播放、0.75× 变速、歌词定位、逐句循环、输入框空格、切页不中断，以及与本地音频互斥。本地 WAV 验证 A–B 回绕及非法范围禁用。标准 / 极高分别返回 MP3 128 / 320 kbps，无损返回 FLAC；该歌曲的 Hi-Res 请求实际降级为无损，界面显示供应商结果。已检查桌面、390px 手机布局和系统明暗切换。

逐字权限仍不可用；逐字间隙与渲染使用模拟歌词验证，音质请求失败后的旧音频保留使用模拟错误验证。DSP 引擎沿用现有实现并通过自动化测试，本轮浏览器验收使用原生播放，不能据此声称 DSP 已完成真实浏览器验收。没有执行线上部署或读屏软件验收。

全屏及句级遮罩补充验证：系统全屏、退出按钮、Esc、浏览器外部退出、原页面恢复、原媒体与歌词节点保留、全屏下的倍速和歌词列表均在本地 Chromium 检查。本地 WAV 进入全屏仍保持同一媒体，另一来源暂停。390px 窗口内全屏、系统全屏拒绝回退及弹窗优先处理 Esc 使用模拟 API 条件；没有测试实体 iPhone。真实 LRC 遮罩在原曲 8s / 9.5s 推进，0.6× 媒体时钟与歌词时钟一致；模拟逐字数据保留 20.4–21.5s 间隙，不提前点亮后一字。显示开关保留同一 core DOM；深色与减少动态效果下保留暂停进度。
