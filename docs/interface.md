# 界面与交互

保留 React、Tailwind、coss ui / Base UI，以及现有连续侧栏和主画布。界面优化使用仓库内的 better-interface、better-accessibility、better-layout、better-writing、better-typography、better-colors、better-ui、transitions-dev 与 transitions-polish。

## 排版与布局

- 常规操作使用 14–16px，辅助信息使用 12px；课程罗马音和释义使用 16px。在线歌词在小屏使用 22px 主文字与 16px 辅助文字，大屏保留较大的学习字号。
- 基础控件恢复 coss ui 原有尺寸分级：普通按钮 36/32px、sm 按钮 32/28px、普通页签 34/30px（手机/桌面）。粗指针按钮沿用 coss ui 的扩展命中区域，不通过增大所有控件占位撑开布局。滑块恢复紧凑占位；业务区采用 8/12/16px 间距，避免纵向间距叠加。
- 手机导航展示四个入口，课程列表和练习正文分别占据工作区。选择课程后回到练习页签并保持键盘焦点；朗读和掌握操作位于当前课程阅读列表前。
- 桌面侧栏支持折叠到 64px，保留 logo、导航图标与展开按钮；文字和数量渐隐收起，宽度使用 350ms smooth-out 过渡。图标保留可访问名称、选中状态和悬停提示，折叠按钮支持键盘并提供展开状态。全屏退出恢复原折叠状态，手机保留文字导航，减少动态效果时立即切换。
- 手机播放控制保留播放、上一句、下一句和循环。「播放设置」展开速度、变速处理、网易云音质及全屏。播放准备与回退通过状态徽标显示，点击可查看详细信息。
- 播放按钮保持固定占位，加载时只显示转圈，不叠加播放或暂停图标。播放条曲名与歌手单行显示，溢出复用带左右渐变遮罩的 MarqueeText。变速与准备状态使用固定高度的图标徽标，点击查看完整状态、实际音质及回退原因；状态变化不再插入提示行或撑高播放条。
- 歌曲列表的标题与歌手保持单行。参考 PickIt 的 MarqueeText，只在实际溢出时按约 30px/s 往返滚动，两端停留，左右渐变遮罩同步移除已露出文字一侧的遮罩；减少动态效果时关闭遮罩并使用省略号。尺寸变化重新测量，隐藏的列表暂停动画，卸载时释放动画与观察器。整行承担 hover 背景，歌曲和收藏按钮保留独立操作与焦点。在线歌词的小屏页头隐藏次要专辑信息，可通过「歌词列表」查看完整歌曲信息与试听范围。
- 弹窗内容独立滚动并考虑底部安全区；页面提供「跳到练习内容」链接。关闭弹窗恢复触发按钮焦点，隐藏的工作区保持 inert。

## 状态与恢复

加载占位按真实组件结构绘制骨架：搜索行保留封面、曲名、歌手、时长与收藏位置；歌词使用原视口与响应式字号，课程和复习保留对应布局，二维码保留 208px 图像及卡片尺寸。分页、账号按钮和播放状态徽标保持占位，加载提示仅通过读屏状态提供，不插入可见文字行。按钮与播放器统一使用无外圈的 Loader；系统减少动态效果时骨架停止闪动。

搜索加载、结果数量、空结果与失败分别反馈；加载时不显示空结果结论。收藏空状态提供返回搜索入口。账号连接状态合并到搜索标题旁的账号按钮，详细的曲库与播放权限在账号弹窗中展示。搜索页签与首条结果之间保留 8px，结果数量只在分页区显示。移除重复标语、英文装饰标题和虚构的用户身份，保留操作、错误恢复、播放权限与本地文件说明。颜色与循环区间错误关联到相应输入框，颜色提交失败将焦点返回输入框。课程提示可以关闭。

在线歌词沿用 AMLL 的独立滚动与媒体时钟。手动滚动后显示「回到当前句」，通过同一 core 的 resetScroll 恢复跟随，不创建另一份歌词或播放状态。手机关闭非当前歌词模糊，便于阅读。

## 动效

`index.css` 仅定义所用的 motion tokens；组件通过 Tailwind class 使用它们，没有增加动效依赖或业务样式文件。

| 交互            | 行为                                                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 按钮与开关      | 150ms；按钮可使用 static 关闭按下缩放，阅读列表保持稳定                                                                                    |
| 播放 / 收藏图标 | 150ms 的透明度、缩放与模糊过渡，双图标保留在 DOM 中，可中断                                                                                |
| 弹窗            | 250ms 打开、150ms 关闭；桌面缩放 0.96，手机保留底部弹窗方向                                                                                |
| 选择器          | 250ms 打开、150ms 关闭；保留 Base UI 的定位与键盘行为；播放器三个选择器统一向上并左对齐触发按钮、6px 间隔，宽度按各自内容自然撑开          |
| 页签指示        | 250ms，使用 cubic-bezier(0.22, 1, 0.36, 1)                                                                                                 |
| 内容切换        | 页签内容立即显示，保留指示条过渡，避免学习正文切换时短暂变淡                                                                               |
| 全屏播放        | 400ms 进入、350ms 退出；侧栏、页头与曲库渐隐收缩，主画布与歌词区域连续改变宽高，播放器同步调整边距；可中途反向切换，减少动态效果时立即切换 |
| 明暗与主题色    | 更新时暂时抑制 transition，下一帧恢复，避免全页颜色拖尾                                                                                    |

减少动态效果时关闭位移、缩放、模糊过渡与背景漂移，保留静态状态提示。forced-colors 使用系统焦点轮廓。

## 验证

运行根目录 typecheck、lint、test、format:check、build 和 git diff --check。浏览器覆盖 320、390、768、1024、1440px 的四个工作区，并额外检查短屏、缩放、主题持久化、弹窗焦点、减少动态效果、播放设置、歌词定位与循环。

音频检查区分 DSP 与原生播放。DSP 使用播放器及歌词的原曲时钟，不能用隐藏 audio 的 paused 或 currentTime 推断状态。真实网易云播放与本地 WAV 检查切页、倍速、定位、循环和互斥；模拟异常验证不等同于重新登录、会员范围或生产部署验收。
