# 保音高变速

本地音频和网易云播放器默认选择「高品质」，使用 Signalsmith Stretch 1.3.2 的 WASM / AudioWorklet 对已解码的音频做时间伸缩。播放速度支持 0.6×、0.75×、0.9×、1×，音高偏移固定为零。播放器中的「原生」选项使用浏览器自带的保音高播放，可以直接比较两种效果。

DSP 在浏览器执行，不增加 Vercel Functions 的音频处理负担，不上传本地文件，也不将网易云歌曲下载到磁盘。TTS 继续使用现有语音朗读；这里处理的是本地文件和曲库歌曲。

## 播放与回退

第一次播放先读取和解码整个音频，再把 PCM 转移到工作线程。因此首次启动比原生播放慢，页面显示「正在准备保音高音频…」，可随时暂停、换歌或切换音质。恢复同一来源的普通暂停可复用 DSP 缓冲；开始另一个播放器或 TTS 时，释放旧来源的 DSP 缓冲以控制内存，保留其播放位置。

以下情况回退到原生播放并显示原因：AudioWorklet / 安全上下文不可用、CDN 不允许跨域读取、读取或解码失败、加载超过 45 秒、DSP 处理器运行失败，或者文件超过内存预算。编码文件上限为 32 MiB，解码 PCM 上限为 128 MiB；解码前也按整个文件的时长、浏览器采样率和双声道预估内存。解码过程还有临时内存开销，实际峰值高于 PCM 预算，超长歌曲优先使用原生播放。

回退和手动切换保留原曲位置、倍速、音量及练习范围。原生媒体元素不强制设置 `crossOrigin`，避免 DSP 的跨域失败同时破坏原生播放。

## 时间轴与权限

界面始终显示原曲秒数，而不是慢速播放的墙钟时长。DSP 时钟以 AudioContext 和已排定的输出起点计算，补偿库的处理前瞻；暂停、seek 和倍速变化重新设置锚点，循环在 worklet 内执行。DOM 定时器只更新界面，不负责 DSP 循环的精度。

网易云原有会员 / 购买 / 试听判定仍由 API 负责。DSP 只把实际允许播放的片段转移到 worklet，所有跳转和循环都受该范围约束；过期地址依旧要求重新选择歌曲。播放记录读取播放器累计播放的媒体秒数，跳转距离、加载等待和暂停不会计入。

大幅慢放、短循环边界和复杂伴奏仍可能产生过渡或时间伸缩伪影，保音高不等于完全无失真。输出设备自身延迟和真实移动设备表现需要实机试听。

## 代码职责

| 文件                                             | 职责                                                                |
| ------------------------------------------------ | ------------------------------------------------------------------- |
| `apps/web/src/lib/stretch-engine.ts`             | AudioContext、WASM 工作线程、授权片段缓冲、输出排期、音量与资源释放 |
| `apps/web/src/lib/audio-transport.ts`            | 原生 / DSP 技术适配、取消加载、音质切换、回退、实际播放累计时间     |
| `apps/web/src/lib/audio-clock.ts`                | 原曲时钟、循环取模与内存预算                                        |
| `apps/web/src/hooks/use-audio-playback.ts`       | 将技术播放器接到 React 媒体节点与状态                               |
| `use-local-audio.ts` / `use-netease-practice.ts` | 各自的文件、歌词、账号、权限与练习业务                              |

第三方库通过动态导入加载；工作线程使用 Vite 发出的独立 `.mjs` 资源，WASM 已内嵌在该资源中，无需远程运行时代码。保留 1.3.2 的兼容性说明：空闲分支需要一个未连接的输入；`schedule()` 的 `outputTime` 与 `output` 两个字段均需设置；不要用未来的 stop 排期覆盖当前活动片段。升级库时重新检查这些行为。

## 验证

自动测试覆盖时间轴、多次循环、内存边界、加载中暂停 / 切歌、失败回退、过期拦截、切换音质的位置与播放记录、音频互斥的缓冲释放。

浏览器验证使用生产构建、本地立体声测试音，以及已授权账号取得的网易云《spiral》音频和歌词。账号 / 曲库 API 响应在本地测试服务中固定，音频仍从真实网易云 CDN 读取；这不能替代重新登录或生产部署验收。0.6× 的测试音频率保持约 440 / 660 Hz，另检查倍速时间推进、逐句 / A–B 循环、切页不中断、互斥、错误提示和手机尺寸布局。测试浏览器的 AudioWorklet 限制与输出设备听感需要分别报告。
